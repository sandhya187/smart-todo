# 📝 Smart Todo App (React)

A simple and smart Todo application built using **React.js**.  
This app allows users to add, edit, and delete todos.Data is saved using **LocalStorage**.


## 🚀 Features
- Add new todo
- Edit todo
- Delete todo
- Save data in LocalStorage

## 🛠️ Tech Stack
- React.js
- JavaScript
- CSS
